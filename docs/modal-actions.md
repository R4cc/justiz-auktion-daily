# Modal actions

Completion screens use one primary **Continue / Weiter** action. Case results may offer a secondary **Buy another case** with the current price when the same case is available and affordable. Daily/tier rewards and retired case types do not suggest an unrelated purchase. Rewards are already saved; dismissal does not sell, restock, or spend anything.

Task dialogs retain the inputs and choices needed for their task. Avoid adding shortcuts to other pages or other tasks. Advanced auction listing completes on the current inventory page, preserving its filters. Store-task drafts survive closing and reopening the editor.

| Surface reviewed | Action pattern |
|---|---|
| Palette opening, including legacy results | Continue to inventory; no restock or auction-house choices. The reveal can be left early with Close. |
| Opened paid case | Continue; optional available repeat purchase. |
| Opened Daily or other tier reward | Continue. |
| Purchased sealed case | Open case or Continue with it sealed. |
| Daily case claim | Open now or add the sealed case to inventory. |
| Completed theft and police wheel | Continue on the current storefront. |
| Store-event acknowledgement | Continue acknowledges the saved events. |
| Ended auction outcome | Continue; an unopened winning palette retains its reveal action. |
| Original auction details and help | Dismissal; original-source information remains in the details. |
| Inventory item details | Item-management controls, gallery and disclosures; Close returns to inventory. |
| Listing editor | Quantity, price, duration and submission; complete in place. |
| Store settings, stock and upgrades | One selected task, its controls and Close; no task-switching tabs or supply-page shortcut inside the modal. |
| Town purchase and takeover | Review and confirm the selected purchase; back/cancel where needed. |
| Store selection for restocking | Select the destination store or close. |
| Review-pack redemption | Choose rating/store and redeem or close. |
| Loan confirmation | Confirm the displayed terms or cancel. |
| Prestige selection | Select the permanent buff, acknowledge the reset and confirm, or cancel. |
| Police recognition and jail | Required penalty choices or release checks; ordinary dismissal stays blocked. |

Escape and backdrop clicks follow each dialog's cancellation rules. Mandatory penalties, pending Daily claims and a spinning police wheel cannot be bypassed by clicking the backdrop. Completed case receipts/results use shared rendering so an open dialog updates its labels when the language changes without repeating a purchase or draw.
