# Auction text decoding

The collector uses the complete WHATWG HTML character-reference table bundled in `src/html-entities.json`. This covers all 2,231 named references, including parentheses (`&lpar;`, `&rpar;`), references with digits, multi-code-point symbols, and legacy semicolonless names. Decimal and hexadecimal numeric references support Unicode scalars, the HTML C1 replacements, and the replacement character for invalid scalar values. Unknown references follow HTML parsing rules. Attribute decoding respects the standard boundary rule so URL parameters such as `&copy=2` remain intact.

Real HTML tags, scripts and styles are removed before references are decoded. Encoded angle brackets therefore survive as ordinary text and continue through the existing HTML-escaping renderers. Text is decoded once, preserving intentionally literal entity syntax. The source's auction-ID suffix is removed only from fallback titles, without stripping product parentheses. The description length limit counts Unicode code points to avoid splitting surrogate pairs.

On the first database opening after this update, a transaction repairs previously unsupported named references and semicolonless references in title/description fields across archives, Daily snapshots, inventory, stored case rewards, and frozen palette pools/rewards. The denormalized archive title is updated for searches. Prices, scores, owners, identifiers and URLs are preserved. References handled by the old collector are left alone to avoid another decode of already-normalized literal text. The `auction_text_entities_v1` marker prevents repeat repairs. Text previously removed by the old tag stripper cannot be reconstructed from saved records; recollecting its source restores that text.

The table is used offline in production. To refresh it from the standard, run `node scripts/generate-html-entities.mjs`. Its source is https://html.spec.whatwg.org/entities.json, documented at https://html.spec.whatwg.org/multipage/named-characters.html. The browser regression compares every bundled named reference with Chrome's native HTML parser and exercises safe rendering through Daily, inventory, the Auction House, admin archive, and Higher or Lower.
