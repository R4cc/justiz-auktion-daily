### UI Copy and Content Density

- Prioritize concise, functional UI copy over descriptive or promotional language.
- Do not automatically add subtitles, descriptions, taglines, or supporting text beneath headings, cards, or sections.
- Only include secondary text when it communicates information necessary for understanding, decision-making, or completing an action.
- Avoid filler microcopy, motivational phrases, marketing language, and explanations of self-evident functionality.
- Prefer short, descriptive labels. A heading or button label should stand on its own whenever possible.
- Do not invent text merely to fill empty space or make a layout appear more complete.
- When reviewing generated UI, remove any text that can be deleted without reducing usability or removing meaningful information.
- Prefer using questionmark tooltips to display explaining information.

### Git Operations

- Always push your changes directly to main, no separate branches.
